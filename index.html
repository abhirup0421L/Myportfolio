Priva

Private Real-Time Chatting Web Application

Priva is a modern real-time private messaging web application designed for secure and seamless communication between users. Built with a responsive and interactive interface, the platform enables one-to-one live chatting with instant message delivery and real-time online status tracking. The application features a complete authentication system with email OTP verification, unique user ID creation, secure password handling, friend searching, and friend management. Users can connect, chat instantly, and view online/offline presence dynamically. Priva is developed using React.js for the frontend, FastAPI for backend APIs and real-time communication, and MongoDB Atlas for cloud database management. The project focuses on delivering a smooth user experience with responsive UI, efficient backend logic, and scalable architecture for modern communication systems.
